# ごはんボード

## 誰の、どんな困りごとか
家族の食事を準備する人が、家族それぞれの食事の必要・不要や起床時間、帰宅時間を把
握できず、食事の準備や買い物に手間がかかるという課題を解決する。 
現在はLINEや紙のカレンダーで予定を共有しているが、家族全員分の情報をまとめて確
認することが難しい。

## コア機能1つ
家族全員の食事・生活時間共有機能 

1.家族一人ひとりが、以下の情報を入力できる。 
    ・朝・昼・夜それぞれの食事が必要か（必要・不要） 
    ・起床時間/帰宅時間 

2.入力した情報は家族全員分まとめて確認できる。また、画面を切り替える
  ことで、日ごとの一覧表示とカレンダー形式の表示を選べるようにする。

## 誰が・いくら・なぜ払うか
誰が⇒家族で食事を作ったり、食事の予定を管理する人
いくら⇒毎月100円
なぜ払うか⇒家族全員の食事や生活時間を一括で確認でき、LINEで何度も連絡したり、紙のカレンダーを確認したりする手間を減らせるため、少額で日々の家事負担を軽減できることに価値があると考える。他のアプリと差別化し、「家族間で本当に共有したいこと」に特化することで需要を高める。 

## 17:15 に見せる操作
一日分だけ、ごはんの必要・不要をボタンで入力する画面を作る
